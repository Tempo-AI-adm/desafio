# desafio

App web mobile-first pra grupos pequenos rodarem desafios de constância. Ver `PRD.md` (o quê), `STYLE.md` (visual/copy) e `CLAUDE.md` (regras de execução).

## Rodando local

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
